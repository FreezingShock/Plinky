Zone 2 Ember Quarry. Generated by `python3 tools/art/gen_quarry.py` (numpy + Pillow; props from tools/art/qprops.py, shapes from tools/art/qs.py).
- One 1400x760 canvas at (0, 0): `quarry/ground.png`, `quarry/walkable.png` (white = walkable, same size), `quarry/sprites/*.png` (front-facing props, y-sorted by `foot`), `quarry/lava/*.png` (6 frame strips, cycled by world/lava_flow.gd), `quarry/placements3d.json` (`world` rect, anchors: pads, gate, arch, player_spawn, vents with a radius, lava ember spots).
- `quarry/preview_full.png` is the composed scene without pads, for reference only.
- `ladder/`: the six pad objects (front-facing 2D) from `python3 tools/art/gen_quarry_ladder.py`.
- `python3 tools/art/gen_zone2.py concepts OUTDIR` still renders the three old concept mockups.
