Dev console overhaul: a floating window you can drag and resize, with the input focused on open. Tab completes commands and their arguments, Up and Down recall history, and help is grouped with short names (g, s, t, w, sp, sea). New: `time set day|night|noon|dawn|dusk|midnight|hh:mm`, `time add 30m|2h|1d`, `season set`, `weather clear|rain|auto`, `speed 2x`, `tp area <id>`, `tp zone <id>`, `reset speed` and `reset weather`.
