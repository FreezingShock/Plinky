# Playing a Plinky test build

**Windows:** unzip, run `Plinky.exe`. If SmartScreen warns, click More info, then Run anyway (the build is unsigned).

**macOS:** unzip, then right-click `Plinky.app` and choose Open the first time (the build is unsigned, so a double-click is blocked). If it still refuses, run `xattr -cr Plinky.app` in Terminal.

**Controls:** click pads to press (hold to repeat), click the ground to walk, Tab upgrades, R relics, F10 settings, F11 fullscreen, F8 feedback.

**Feedback:** press F8, type a note, Save note. Copy all puts every note on your clipboard so you can paste it into a message. Notes live in `feedback.txt` in the game's data folder (Open folder button). Nothing is sent anywhere.

**Saves** are local: `save.json` in the same folder. Delete it to start over.
